🔍 OpenCut 场景名称显示测试

1. 数据层（应该显示标识符）

在数据库和代码中，主场景应该使用内部标识符：

{
  "id": "scene-123",
  "name": "__main_scene__",  ✓ 这是正确的
  "isMain": true
}

说明：这是预期行为，数据库中存储标识符而不是翻译文本。

3. 如何验证

  1. 启动项目：cd apps/web && npm run dev
  2. 打开浏览器：http://localhost:3000
  3. 创建新项目或打开现有项目
  4. 点击编辑器中的 场景 按钮（通常在时间轴附近）
  5. 查看场景选择器侧边栏

场景选择器中应该看到：

主场景 ✓

❌ 错误： 如果显示 __main_scene__
✓ 正确： 如果显示 主场景 或 Main scene

4. 常见误解

位置 显示内容 是否正常
IndexedDB 数据库 __main_scene__ ✓ 正常
localStorage __main_scene__ ✓ 正常
控制台日志 __main_scene__ ✓ 正常
场景选择器 UI 主场景 ✓ 正常
场景选择器 UI __main_scene__ ✗ 异常（需要修复）
