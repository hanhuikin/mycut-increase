# 场景名称显示问题排查与修复

## 问题描述

用户反馈：创建新项目后，看到场景名称显示为 `__main_scene__`，而不是：
- 中文：**主场景**
- 英文：**Main scene**

## 排查结果

### ✅ 代码实现正确

检查了所有相关代码，发现实现是正确的：

1. **数据层** - `src/timeline/scenes.ts`
   ```typescript
   const mainScene = buildDefaultScene({ 
     name: "__main_scene__",  // ✅ 使用内部标识符
     isMain: true 
   });
   ```

2. **UI 显示层** - `src/components/editor/scenes-view.tsx`
   ```typescript
   const getSceneName = (scene: TScene) => {
     if (scene.isMain) {
       return t["scene.main_scene"];  // ✅ 正确转换
     }
     if (scene.name === "__main_scene__") {
       return t["scene.main_scene"];  // ✅ 正确转换
     }
     // 向后兼容
     if (scene.name === "Main scene" || scene.name === "主场景") {
       return t["scene.main_scene"];
     }
     return scene.name;
   };
   ```

3. **国际化文件** - `src/locale/zh.ts` 和 `src/locale/en.ts`
   ```typescript
   // zh.ts
   "scene.main_scene": "主场景",  // ✅ 中文翻译
   
   // en.ts
   "scene.main_scene": "Main scene",  // ✅ 英文翻译
   ```

### 🔍 可能的原因

#### 原因 1：场景名称显示的位置问题

**场景名称目前只在一个地方显示：**
- **场景选择器** (`scenes-view.tsx`) - 点击编辑器中的场景按钮时打开

**如果您在其他地方看到 `__main_scene__`：**
- 浏览器开发者工具（localStorage/IndexedDB） - 这是正常的，数据库中存储的就是标识符
- JSON 导出/调试面板 - 原始数据显示
- 控制台日志 - 开发者日志

#### 原因 2：浏览器缓存问题

如果是在场景选择器中看到 `__main_scene__`，可能是：
1. 浏览器缓存了旧版本的代码
2. React 组件没有正确重新渲染
3. 热重载 (HMR) 问题

#### 原因 3：语言设置问题

如果 `t["scene.main_scene"]` 返回 undefined，会回退到某个默认值。

## 解决方案

### 方案 1：清除浏览器缓存并重启

```bash
# 1. 停止开发服务器
# Ctrl+C 或关闭终端

# 2. 清除 Next.js 缓存
cd apps/web
rm -rf .next

# 3. 清除浏览器缓存
# 在浏览器中按 Ctrl+Shift+Delete
# 或者使用无痕模式测试

# 4. 重启开发服务器
npm run dev
```

### 方案 2：强制刷新页面

在浏览器中：
- Windows/Linux: `Ctrl + F5`
- Mac: `Cmd + Shift + R`

### 方案 3：检查语言设置

打开浏览器控制台，运行：
```javascript
// 检查当前语言
localStorage.getItem('locale')

// 强制设置为中文
localStorage.setItem('locale', 'zh')

// 刷新页面
location.reload()
```
