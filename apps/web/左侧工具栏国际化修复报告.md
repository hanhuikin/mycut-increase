# 左侧工具栏详情页面国际化修复报告

## 修复日期
2026-09-11

## 问题描述
用户反馈：在中文环境下，左侧工具栏中的详情页面仍然显示英文或错误地只显示中文（无法切换语言）：
1. ✅ 字幕详情内部
2. ✅ 特效详情内部
3. ✅ 贴纸详情内部
4. ✅ 文字详情内部
5. ✅ 音频详情内部
6. ✅ 设置详情内部（已经正确实现）

## 根本原因

这些组件直接导入并使用了 `zh` 对象：
```typescript
// ❌ 错误做法
import { zh } from "@/locale/zh";
// 使用
<Button>{zh["some.key"]}</Button>
```

**问题**：
- 无论当前语言设置是什么，都只显示中文
- 无法响应语言切换
- 违反了国际化最佳实践

## 修复方案

将所有组件改为使用 `useLocale()` hook：
```typescript
// ✅ 正确做法
import { useLocale } from "@/locale/locale-context";

export function MyComponent() {
  const { t } = useLocale();
  return <Button>{t["some.key"]}</Button>;
}
```

## 修复方法

使用批量替换脚本：

```bash
# 批量替换导入语句
for file in apps/web/src/{text,stickers,effects,sounds,subtitles}/components/assets-view.tsx; do
  sed -i 's/import { zh } from "@\/locale\/zh";/import { useLocale } from "@\/locale\/locale-context";/' "$file"
  sed -i 's/zh\[/t[/g' "$file"
done

# 手动在每个组件函数中添加 const { t } = useLocale();
```
