```typescript
console.error(t["error.audio_generation_failed"], error);
```

**或保持原样（开发日志）：**
```typescript
// ✅ 可接受：开发日志用英文
console.error("Audio generation failed:", error);
```

## 自动化修复建议

### 创建批量替换脚本

可以创建一个脚本来批量替换常见模式：

```javascript
// scripts/fix-i18n-batch.js
const replacements = [
  {
    pattern: /"16:9（横屏）"/g,
    replacement: 't["ai_video.aspect_ratio_16_9"]',
    files: ['**/ai-video.tsx']
  },
  // ... 更多替换规则
];
```

### 使用 AST 工具

对于复杂的替换，可以使用 AST（抽象语法树）工具如 jscodeshift：

```bash
npm install -g jscodeshift
jscodeshift -t transform.js src/
```

## 验证流程

### 1. 添加翻译键
在 `zh.ts` 和 `en.ts` 中添加所有需要的键

### 2. 替换代码
将硬编码文本替换为 `t["key"]`

### 3. 类型检查
TypeScript 会自动检查键是否存在：
```typescript
// 如果键不存在，TypeScript 会报错
const text = t["non_existent_key"]; // ❌ 类型错误
```

### 4. 运行检查
```bash
npm run check:i18n
```

### 5. 测试两种语言
- 切换到中文，检查显示
- 切换到英文，检查显示

## 快速修复模板

### Toast 消息
```typescript
// Before
toast.error("操作失败");
toast.success("操作成功");

// After
toast.error(t["toast.operation_failed"]);
toast.success(t["toast.operation_success"]);
```

### 下拉选项
```typescript
// Before
const options = [
  { value: "1", label: "选项一" },
  { value: "2", label: "选项二" },
];

// After
const options = [
  { value: "1", label: t["option.one"] },
  { value: "2", label: t["option.two"] },
];
```

### 动态文本
```typescript
// Before
const message = `处理了 ${count} 个文件`;

// After
const message = t["message.processed_files"].replace("{count}", String(count));
// 或在翻译文件中定义: "message.processed_files": "处理了 {count} 个文件"
```
