## 完整修复清单

### 1. 场景名称显示 ✅

**问题**: 时间轴工具栏中间显示 `__main_scene__` 而不是"主场景"

**文件**: `apps/web/src/timeline/components/timeline-toolbar.tsx`

**修复**:
```typescript
// 添加导入
import { useLocale } from "@/locale/locale-context";

// SceneSelector 组件
function SceneSelector() {
  const { t } = useLocale();
  const getSceneName = (scene) => {
    if (scene.isMain || scene.name === "__main_scene__") {
      return t["scene.main_scene"];
    }
    return scene.name;
  };
  // ...
}
```

**效果**: 中文显示"主场景"，英文显示"Main scene"

## 修复模式总结

### 错误模式 ❌

#### 1. 直接导入语言对象
```typescript
import { zh } from "@/locale/zh";
<Button>{zh["key"]}</Button>
```
**问题**: 无法切换语言，永远显示中文

#### 2. 硬编码文本
```typescript
<Button>Import</Button>
<SelectItem>Fit</SelectItem>
```
**问题**: 永远显示英文

#### 3. 直接显示内部标识符
```typescript
<SplitButtonLeft>{currentScene?.name}</SplitButtonLeft>
```
**问题**: 显示 `__main_scene__` 而不是翻译文本

---

### 正确模式 ✅

#### 1. 使用 useLocale Hook
```typescript
import { useLocale } from "@/locale/locale-context";

export function MyComponent() {
  const { t } = useLocale();
  return <Button>{t["key"]}</Button>;
}
```

#### 2. 为内部标识符添加转换逻辑
```typescript
const getSceneName = (scene) => {
  if (scene.name === "__main_scene__") {
    return t["scene.main_scene"];
  }
  return scene.name;
};
```

#### 3. 所有用户可见文本使用翻译键
```typescript
// 按钮
<Button>{t["media.upload"]}</Button>

// 标题
<PanelView title={t["assets.assets"]} />

// 占位符
<Input placeholder={t["media.search"]} />

// Tooltip
<ToolbarButton tooltip={t["timeline.split_element"]} />
```

## 技术要点

### TypeScript 类型安全
所有翻译键都有类型检查：
```typescript
export type LocaleStrings = typeof zh;
// t["non_existent_key"] 会报错
```

### 性能考虑
- `useLocale` 使用 Context，避免 prop drilling
- 翻译对象在顶层创建，不会重复创建
- 语言切换时自动重新渲染

### 向后兼容
场景名称处理保留了向后兼容：
```typescript
// 支持旧的硬编码名称
if (scene.name === "Main scene" || scene.name === "主场景") {
  return t["scene.main_scene"];
}
```

## 最佳实践

### ✅ DO
1. 总是使用 `useLocale()` hook
2. 所有用户可见文本使用翻译键
3. 在 zh.ts 和 en.ts 中同步添加翻译
4. 使用语义化的键名（如 `timeline.split_element`）
5. 在组件函数顶部调用 `useLocale()`

### ❌ DON'T
1. 不要直接导入 `zh` 或 `en`
2. 不要硬编码任何语言的文本
3. 不要忘记添加对应的英文翻译
4. 不要在循环或条件中调用 `useLocale()`
5. 不要在运行时构建翻译键
