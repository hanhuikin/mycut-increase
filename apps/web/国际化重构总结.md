# 国际化重构总结

## 问题描述

用户发现项目中的场景命名存在中英文混用的问题：
- 代码中同时出现了 `__main_scene__`、`"Main scene"` 和 `"主场景"`
- 中英文没有完全隔离，难以维护和扩展

## 解决方案

### 1. 统一内部标识符

**所有主场景在数据层统一使用：**
```typescript
const MAIN_SCENE_IDENTIFIER = "__main_scene__";
```

**修改的文件：**
- ✅ `src/timeline/scenes.ts` - 已使用 `__main_scene__`
- ✅ `src/core/managers/project-manager.ts` - 已使用 `__main_scene__`
- ✅ `src/services/storage/migrations/transformers/v0-to-v1.ts` - 已修改为使用 `__main_scene__`

### 2. 显示层国际化

**UI 显示时通过国际化键获取翻译：**
```typescript
// 中文
t["scene.main_scene"] // "主场景"

// 英文  
t["scene.main_scene"] // "Main scene"
```

**已实现的文件：**
- ✅ `src/components/editor/scenes-view.tsx` - 已实现 `getSceneName()` 函数处理国际化
- ✅ `src/locale/zh.ts` - 包含 `"scene.main_scene": "主场景"`
- ✅ `src/locale/en.ts` - 包含 `"scene.main_scene": "Main scene"`

### 3. 向后兼容

UI 层会自动处理旧数据中的硬编码名称：
```typescript
const getSceneName = (scene: TScene) => {
  if (scene.name === "__main_scene__") {
    return t["scene.main_scene"];
  }
  // 向后兼容旧格式
  if (scene.name === "Main scene" || scene.name === "主场景") {
    return t["scene.main_scene"];
  }
  return scene.name;
};
```

### 4. 数据迁移

创建了迁移函数将旧项目中的硬编码名称转换为标识符：
- ✅ `src/services/storage/migrations/transformers/normalize-main-scene-name.ts`

此迁移会将所有 `"Main scene"` 和 `"主场景"` 自动转换为 `"__main_scene__"`

## 使用指南

### 创建新场景

```typescript
// ✅ 正确：主场景使用标识符
const mainScene = buildDefaultScene({ 
  name: "__main_scene__", 
  isMain: true 
});

// ✅ 正确：自定义场景使用用户输入的名称
const customScene = buildDefaultScene({ 
  name: userInput, 
  isMain: false 
});
```

### 显示场景名称

```typescript
import { useLocale } from "@/locale/locale-context";

const { t } = useLocale();

// ✅ 正确：通过国际化获取名称
const displayName = scene.isMain || scene.name === "__main_scene__"
  ? t["scene.main_scene"]
  : scene.name;
```

### 添加新的翻译

1. 在 `src/locale/zh.ts` 添加中文：
```typescript
export const zh = {
  // ...
  "your.new.key": "你的中文翻译",
};
```

2. 在 `src/locale/en.ts` 添加英文：
```typescript
export const en = {
  // ...
  "your.new.key": "Your English translation",
};
```

3. 在代码中使用：
```typescript
const text = t["your.new.key"];
```
