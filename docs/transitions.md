# 转场（Transitions）

## 一句话原理

片段**不动、不重叠**；转场是骑在两个相邻片段切点上的一块「过渡标记」。渲染时同一条时间线上同时取两段素材（出画 A、入画 B），按进度合成。因此预览、截图、导出看到的是同一个结果。

## 怎么用

1. **先做出接缝**：同一条视频轨上两段首尾相接。可以是切分出来的（选中片段 + `S` 或工具栏剪刀），也可以是先后插入、彼此紧贴的两段。
   - 主轨和 overlay 上的视频轨都支持；跨轨道叠放不算接缝。
2. **把播放头放到接缝附近**（0.5 秒容差内）。
3. 打开左侧 **转场** 面板，点任意预设上的 **＋**。
   - 播放头会自动吸附到接缝；附近没有接缝时会提示「附近没有片段交界」。
   - 插入后时间轴多出一条**转场轨**（细行，紧贴主轨上方），块以切点为中心、左右各占一半时长。
4. **调整**：选中转场块，右侧属性面板可改
   - **时长（秒）**：默认 0.5s，会被较短一侧片段长度钳制（一块转场最多吃掉两侧片段各一半）。
   - **方向**：推移 / 擦除用（向左、向右、向上、向下）。
   - **羽化**：擦除 / 圆形扩展用（0–50，越大边缘越软）。
   - **强度**：缩放 / 旋转 / 模糊用（0–100）。
5. **删除**：选中块按 `Delete`。块删掉后空的转场轨会被自动清理。

## 内置预设

| 预设 | 效果 | 可调 |
| --- | --- | --- |
| 叠化 | A 保持铺底，B 淡入（标准交叉溶解） | — |
| 黑场 | 前半段 A 淡到黑，后半段 B 从黑淡入 | — |
| 白场 | 同上，但中间闪一层白 | — |
| 推移 | A 沿方向滑出，B 从对侧跟进，两块始终拼满画面 | 方向 |
| 擦除 | B 被一条矩形边界逐渐揭开，A 留在下面 | 方向、羽化 |
| 圆形扩展 | B 以椭圆从中心扩散揭开 | 羽化 |
| 缩放 | B 从放大状态淡入到原尺寸，A 同步推近 | 强度 |
| 旋转 | B 带旋转淡入，A 反向轻转 | 强度 |
| 模糊 | B 从模糊到清晰淡入，A 变模糊淡出 | 强度 |

## 素材手柄与冻结帧

过渡窗口里，出画片段要播到自身结束之后一点，入画片段要从开始之前一点起播：

- 素材还有余量（`trimStart/trimEnd` 之外还有内容）→ 直接取真实画面，和 Premiere / 剪映一致。
- 素材没有余量 → 停在首帧/末帧（冻结帧），这也是主流软件的降级行为。

## 当前限制

- **同一轨道上的片段仍然不能重叠**：时间轴上两段不会互相压住，转场块单独一行骑在切点上；真正的重叠只发生在渲染期。
- **拖走转场块 = 脱离绑定**：块中心离开切点超过半个块宽后不再生效（不会偷偷作用在原切点上）。想恢复就拖回去，或删掉重新插入。
- **转场轨隐藏后转场不生效**（轨道行左侧的眼睛图标）。
- 暂不支持：拖拽插入、转场的声音交叉淡化、跨 overlay 轨道的转场、转场参数关键帧。
- 黑场在「背景不是纯黑」的项目里露出的是项目背景色（画布底色），不是强制纯黑。

## 导出

导出和预览共用同一个合成器（`services/renderer`），所以导出视频里的转场与预览一致，无需额外设置。

## 排查

- 插入没反应：确认播放头在接缝 0.5s 内（接缝 = 同一轨道上前一段结束时间等于后一段开始时间）。
- 看不到过渡：确认转场轨可见、块中心仍在切点上、播放头落在块内。
- 控制台/日志里与转场相关的关键字：`transition`。
