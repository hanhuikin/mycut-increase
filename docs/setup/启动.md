# OpenCut 项目启动指南

## 项目信息
- **项目名称**: OpenCut
- **项目类型**: Next.js Web 应用 + Monorepo (Turbo)
- **包管理器**: npm (原配置为 bun，但系统未安装)
- **端口**: 3000 (本地) / 3001 (备用)

## 快速启动

### 启动 Web 应用
```bash
cd apps/web
npm run dev
```

**访问地址**:
- 本地: http://localhost:3000
- 网络: http://192.168.113.205:3000

## 已知问题与解决方案

### 1. Turbopack 兼容性问题
**问题**: Next.js 16.x 的 Turbopack 在此项目中存在内部错误
```
FATAL: An unexpected Turbopack error occurred
Invariant: Expected to replace all template variables, found VAR_MODULE_GLOBAL_ERROR
```

**解决方案**: 
- 已在 `apps/web/package.json` 中修改 dev 脚本，移除 `--turbopack` 参数
- 使用标准 webpack 编译器代替
- 已创建 `apps/web/src/app/global-error.tsx` 文件

### 2. Bun 未安装
**问题**: 项目配置使用 bun 作为包管理器，但系统未安装

**解决方案**: 使用 npm 代替，功能完全正常

### 3. 端口占用
**问题**: 3000 端口可能被占用

**检查端口占用**:
```bash
netstat -ano | grep :3000 | grep LISTENING
```

**清理占用进程**:
```bash
taskkill //PID <进程ID> //F
```
