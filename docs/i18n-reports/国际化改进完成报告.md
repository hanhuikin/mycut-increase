## 🏗️ 架构设计

### 三层分离原则

```
┌─────────────────────────────────────────┐
│           显示层 (UI Layer)              │
│   使用: t["scene.main_scene"]           │
│   显示: "主场景" / "Main scene"          │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│       国际化层 (i18n Layer)              │
│   zh.ts: "scene.main_scene": "主场景"   │
│   en.ts: "scene.main_scene": "Main scene"│
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│         数据层 (Data Layer)              │
│   存储: "__main_scene__"                 │
│   内部标识符，永不改变                    │
└─────────────────────────────────────────┘
```

### 核心规则

1. **数据层：** 只使用内部标识符 `__main_scene__`
2. **国际化层：** 翻译键值对完全分离
3. **显示层：** 通过 `t[key]` 获取翻译
4. **向后兼容：** UI 层自动识别旧格式


## 📝 使用示例

### 创建场景

```typescript
import { buildDefaultScene } from "@/timeline/scenes";

// ✅ 正确：主场景使用标识符
const mainScene = buildDefaultScene({ 
  name: "__main_scene__", 
  isMain: true 
});

// ✅ 正确：自定义场景使用用户输入
const customScene = buildDefaultScene({ 
  name: userInput,  // 用户输入的名称
  isMain: false 
});
```

### 显示场景名称

```typescript
import { useLocale } from "@/locale/locale-context";

function SceneComponent({ scene }) {
  const { t } = useLocale();
  
  // ✅ 正确：通过国际化获取名称
  const displayName = scene.isMain || scene.name === "__main_scene__"
    ? t["scene.main_scene"]
    : scene.name;
    
  return <div>{displayName}</div>;
}
```

### 添加新翻译

```typescript
// 1. zh.ts
export const zh = {
  "your.new.key": "你的中文翻译",
};

// 2. en.ts
export const en = {
  "your.new.key": "Your English translation",
};

// 3. 使用
const text = t["your.new.key"];
```
