# MyCut 技术与产品文档索引

产品与技术文档统一收放在本目录。`AGENTS.md`（构建/架构约定）与 `README.md`（项目说明）保留在仓库根目录。

## 目录结构

### design/ — 产品与 UI 设计
| 文件 | 内容 |
|---|---|
| `mycut-UI设计稿.html` | 全局 UI 设计稿（视觉基准） |
| `任务队列ui以及交互设计方案.html` | AI 生成任务队列：状态机、列表/详情、布局选型（v2，方案 D 已实施） |
| `管理面板ui交互设计方案.html` | Admin 管理面板（渠道/模型/用户）交互设计 |
| `账户系统ui设计.html` | 登录/注册/账户体系 UI 设计 |
| `AI能力增强.html` | AI 能力规划稿 |
| `参考视频生成视频.html` | 参考视频生成视频 功能设计 |

### plans/ — 规划与部署方案
| 文件 | 内容 |
|---|---|
| `后续开发规划.md/.html` | P0–P4 产品技术路线（OSS、素材归属、七牛接入、部署选型） |
| `架构与部署方案.md` | 仓库架构梳理 + 部署形态对比 |
| `部署方案.html` | 部署方案（历史版本，现行为 K8s 打包部署方案） |
| `../docs/K8s打包部署方案.md` | **现行**：K8s 打包部署（kustomize 双环境 test/prod） |

### i18n-reports/ — 国际化过程报告（24 份）
多语言统一改造期间的排查/修复/验收记录，属于历史过程文档——现状以 `apps/web/src/locale/` 与 `AGENTS.md` 中的国际化约定为准。

### setup/ — 环境搭建
| 文件 | 内容 |
|---|---|
| `启动.md` | 本地启动指南（依赖、env、命令） |

### 根级（本目录直下）— 子系统技术文档
| 文件 | 内容 |
|---|---|
| `AI-INTEGRATION-GUIDE.md` | AI 提供商接入指南（协议/渠道体系） |
| `K8s打包部署方案.md` | K8s 双环境打包部署方案（现行部署依据） |
| `actions.md` / `keyframes.md` / `effects-renderer.md` / `countries-search.md` | 对应子系统技术说明 |

## 约定

- 新的产品/UI 设计稿、规划、部署方案一律放入本目录对应子文件夹，不再放仓库根目录或 `apps/web/`。
- 过程性报告（修了什么、验收记录）放 `i18n-reports/` 同级的对应主题子目录，避免与"现状文档"混放。
- `apps/web/AGENTS.md`、`apps/web/CLAUDE.md` 是代码助手规则文件，不移动。
