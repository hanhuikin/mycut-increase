AI 视频面板 - UI 设计稿

设计需求:
• 支持文生视频 + 图生视频,用 Tab 切换
• 新增「模型选择」下拉框
• 新增「高级配置」折叠区,包含「分镜生视频」功能
• 保持现有设计系统规范(面板布局、Tabs underline 变体、表单样式、间距)
设计系统: 使用 panel 主题变量 + Radix UI Tabs(underline) + 现有 Select/Label/Button 组件

1. 文生视频 Tab (默认)

AI 视频
不同模型的生成速度和效果有差异,默认使用 Seedance 2.0
主:火山方舟 → 备:Atlas Cloud → WaveSpeedAI。默认720p约$0.50/5秒。

2. 图生视频 Tab

AI 视频
点击上传或拖放图片 (JPG, PNG, WebP)
推荐分辨率 1280x720 或更高,最大 10MB
留空则让模型自动决定运动,填写可以引导特定动作
控制画面变化幅度,低强度适合静态场景添加微动
图生视频价格约为文生视频的 1.5 倍,生成时间 2-5 分钟

AI 视频
将长视频拆分为多个镜头分别生成,最后自动拼接。适合复杂叙事和场景切换。

交互说明与技术细节

组件对应关系:

  • Tab 切换: Tabs + TabsList + TabsTrigger (variant="underline")
  • 下拉框: Select + SelectTrigger + SelectContent (现有 select.tsx)
  • 折叠区: Collapsible + CollapsibleTrigger + CollapsibleContent (Radix UI)
  • 表单项: Label + textarea / select (保持现有样式)
  • 按钮: Button (className="w-full")

实现调整 - 模型清单:

  • 上方 mockup 里列出的 Kling 1.6 / CogVideoX / Gen-3 Alpha / Stable Video Diffusion 未实现:现有 provider 链(火山方舟 → Atlas → WaveSpeed → fal)只接了字节 Seedance 系列,填入其他模型 id 会在提交任务时直接被接口拒绝(400),表现为用户点了生成却失败
  • 实际提供两个:Seedance 2.0(文生+图生,支持同步音频,最长 15 秒)和 Seedance 2.0 Turbo(仅文生,无音频,最长 10 秒)
  • 模型的能力差异会驱动 UI:切到 Turbo 后音频开关自动隐藏、时长选项自动截到 10 秒;切到图生视频 Tab 后 Turbo 从下拉框中消失
  • 接入新模型只需在 services/ai-video/models.ts 的 VIDEO_MODELS 里加一项并补两个 locale key,UI 无需改动

状态管理:

  • activeTab: "text-to-video" | "image-to-video"
  • selectedModel: string (模型下拉框,根据 Tab 切换时更新可选项)
  • advancedOpen: boolean (高级配置折叠状态)
  • storyboardEnabled: boolean (分镜模式开关)
  • shots: Array<{id, prompt, duration}> (分镜列表,最少 2 个)

分镜生成逻辑:

  • 勾选「分镜生视频」后,单个 prompt 输入框隐藏,展示分镜列表
  • 每个分镜独立调用 generateVideo(),按顺序生成
  • 实现调整:项目未引入 FFmpeg(仅有 mediabunny),故不做二次编码拼接。改为每个镜头生成后按累计时长依次插入时间轴 video 轨,首尾相接。好处是无损、无需重编码,且每个镜头在时间轴上仍是独立可编辑的片段
  • 转场不在本面板内生成:镜头落到时间轴后,用现有「转场」面板在片段之间添加,复用编辑器已有能力
  • 按钮文案动态更新:「生成视频 (N 个镜头,总计 X 秒)」
  • 进度提示:「生成第 1/3 个镜头 (森林小木屋)...」

样式规范:

  • 间距: gap-4 (16px) 用于主表单项, gap-1.5 (6px) 用于 label-input
  • 圆角: rounded-md (6px) 用于输入框/按钮, rounded-sm (3px) 用于小元素
  • 边框: border (hsl(0, 0%, 87%)) 亮色, border (hsl(0, 0%, 18%)) 暗色
  • 字号: 标签 text-sm (14px), 提示 text-xs (12px), 输入框 text-sm
  • 配色: 主色 primary (hsl(200, 90%, 52%)), 次要 secondary 高亮区
