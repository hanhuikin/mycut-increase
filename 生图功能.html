① 概述与定位

目标：在素材库中提供「文字 → 图片」的直接创作入口：写提示词、选比例与数量、生成后图片自动存入项目素材库，可预览、可一键插入时间轴，形成 生图 → 素材库 → 时间轴 的闭环。

与「多图生成」的关系：互补而非替代。多图生成需要先进入多选、挑 2–4 张参考图（以图为基础改图）；文生图无任何前置素材要求（从零生成）。两者入口并排在素材库头部工具栏，共用同一套参数控件、成本/余额条、结果条带与入库逻辑，降低实现与维护成本。

维度文生图（本次新增）多图生成（已有，不动）
入口素材库头部工具栏「生图」按钮（多图生成左侧）素材库头部工具栏「多图生成」按钮 → 进入多选 → 选 2–4 张 → 底部动作条
前置条件无（点按钮直接开对话框）需选中 ≥2 张图片
形态对话框（生成不中断，关闭再开状态还在）对话框（同）
输入提示词（必填）＋ 风格预设 ＋ 负面提示词（可选）≥2 张参考图 ＋ 提示词（@图N 引用）

结果一致：自动存入项目素材库 · 预览 / 插入时间轴 / 重新生成

预留：v2 可把两个入口收纳为一个「AI 生图」入口（对话框内「文生图 | 多图生成」两个页签），本期不动多图生成，避免回归风险。

② 入口方案

采用素材库头部工具栏「生图」按钮 — 与「多图生成」对齐（评审红框位置）

资源 ✦ 生图← 新增入口 多图生成 ≡ ⇅ ⬆ 上传
  • 位置：标题「资源」与「多图生成」按钮之间，与「多图生成」同一行、同样式尺寸（ghost 小按钮），形成「生图 | 多图生成」AI 生图入口组。
  • 点击直接打开文生图对话框，无任何前置选择；与多图生成（先多选后出对话框）形成明确分工。
  • 不新增 icon 栏 tab，素材栏保持 12 个入口不拥挤；AI 创作动作收敛在素材工具栏。
  • 生成期间若对话框已关闭，入口按钮上显示绿色呼吸点（运行中提示），点击重新打开可继续查看进度。
  • 多选模式进入后隐藏「生图」按钮（与多图生成按钮此时变为「退出多图生成」一致），避免多选状态与文生图动作互相干扰。

备选（不采用）icon 栏新增「生图」tab（常驻面板形态）

  • 优点是能承载更大的历史画廊；但 icon 栏已有 12 个 tab，且与多图生成的入口分离，用户需要在两处找「生图」类功能。按评审意见不采用。

⑤ 交互细节与边界

核心流程

1
素材库 → 点头部工具栏「✦ 生图」（多图生成左侧）→ 打开文生图对话框。
2
输入提示词（或点「灵感」chip 追加模板句；选「风格」在生成时自动拼接风格词到提示词尾部）。
3
选比例 → 尺寸档实时换算短边（长边基准，64 步进吸附）；需要精细控制时点「自定义」在弹层里输入宽高（校验 + 吸附 + 总像素上限）。
4
选数量 1/2/4，成本行实时变为「单价 × 数量」，余额不足即刻禁用。
5
点「生成」或 ⌘↵/Ctrl+↵：按钮变「生成中…」，出现占位卡；逐张请求、逐张点亮（先到先显示）。
6
每张成功后立即自动存入项目素材库（命名 文生图-YYYYMMDDHHmmss.png，与多图生成命名规则对齐），toast「已生成并存入素材库」。
7
结果卡底部操作：预览（遮罩大图，点击空白/Esc 关闭）· 插入（放到播放头所在 overlay 轨，同多图生成行为，可重复插入）· 重新生成（同参数追加一张）。
8
「最近生成」区顶部插入本次记录；点历史卡可预览（「再来一张」= 提示词回填 + 同参数直接生成）。
9
关闭对话框（✕ / Esc / 点遮罩）生成不中断；期间素材入口按钮带绿色呼吸点；重开对话框结果与进度原样恢复。去「资源」网格里也能看到刚生成的图，可拖入时间轴 — 与普通素材完全同权。

边界与异常

场景处理
提示词为空 / 纯空白生成按钮禁用；字数计数 0/2000
生成中修改参数参数控件禁用（与多图生成一致），避免同批参数漂移

数量 4 全部排队串行逐张请求（与多图生成同模式），点数逐张冻结/扣减

余额不足禁用生成 + 红字；不影响已完成结果的查看与插入
重复点「插入」允许，同一素材可在时间轴多处使用
无活动项目生成禁用（与多图生成 activeProject != null 校验一致）
多选模式「生图」按钮隐藏（多图生成按钮此时为「退出多图生成」），退出多选后恢复
历史数量会话级历史上限 40 条，超出丢弃最旧（素材库才是持久层）

⑧ 服务与实施拆分

服务层（与 multiImageToImage 同构）

  • services/ai-tools/index.ts 新增 textToImage({ prompt, negativePrompt?, aspectRatio, imageSize, onProgress? }) → runJob({ params: { modelId: "ai-tools-text2img", input: { prompt, aspect_ratio, image_size, ...(negative_prompt) } } })；每次调用一张，下载 blob → File("文生图-…png")。
  • 渠道映射（服务端）：ai-tools-text2img → 具体生图端点（fal 的 flux 系等），由渠道配置决定，前端不感知；负面词上游不支持时由渠道侧忽略。
  • 计费：模型目录新增 ai-tools-text2img 单价；前端复用 billing.models.get(id) + estimateCost。

状态层

  • components/ai/text2img-store.ts：zustand（与 img2img-store 同模式，与组件解耦 → 关对话框生成不中断），字段 open / prompt / style / negative / aspectRatio / sizePreset / customSize / numImages(1|2|4) / running / results / history；尺寸换算直接复用 img2img-store 的 computeImageSize / resolveImageSize / validateCustomSize / IMG2IMG_SIZE_CAPS（导出共用，不复制）。
  • history 为会话级（不落 localStorage）；素材库为持久层。

UI 层

  • components/ai/text2img-dialog.tsx：Dialog 结构对齐 img2img-dialog.tsx（标题 / 提示词+灵感 / 风格 / 高级负面词 / 参数分段 / 成本+生成 / 结果条带），额外加「最近生成」网格；控件样式复用其 ParamChip/seg 模式。
  • panels/assets/views/assets.tsx：PanelView 的 actions 里、「多图生成」按钮左侧加「✦ 生图」按钮（store.running && !open 时带呼吸点；selectMode 时隐藏）+ 渲染 <Text2ImgDialog onInsertTimeline={…} />。
  • 插入时间轴：复用多图生成宿主已有的插入逻辑（handleImg2ImgInsert 同款：素材资产 → 播放头处建 image 元素），抽公共函数共用。
  • locale：zh.ts / en.ts 成对新增（见⑦）。不改 icon 栏 / assets-panel-store / tab 配置。

验收清单

  • 素材工具栏「生图」按钮位于「多图生成」左侧、同样式对齐；多选模式下隐藏。
  • 空提示词禁用生成；⌘↵ / Ctrl+↵ 可触发；生成中参数与按钮禁用。
  • 生成中关闭对话框：生成不中断、入口按钮呼吸点；重开恢复结果与进度。
  • 结果自动出现在「资源」网格，可拖入时间轴；「插入」落在播放头处且可重复。
  • 比例切换时尺寸档文案实时换算；自定义尺寸校验、64 吸附、总像素上限。
  • 数量 4 成本 ×4；余额不足禁用；模型未配置黄字提示。
  • 失败仅标记单张，可重试，同批其他张不受影响。
  • zh / en 切换完整无缺 key；tsc / eslint / next build 通过。
