01

设计基础与令牌

Foundations

编辑器是「密集操作面」：一屏之内同时存在素材库、画布、参数与时间轴四条信息流。 因此基础层只有一条主线——把颜色让给内容，把对比度让给状态。 界面自身近乎无彩（中性灰阶），彩色只出现在三类地方：品牌主色（可操作）、 轨道类型色（可辨识）、AI / 计费提示（需注意力）。

1.1 设计原则

原则说明落地证据
无彩界面 全局用中性灰构成层级（背景 5% → 面板 10% → 强调面 14% → 悬停 21%）。颜色不承担结构职责，只承担状态职责。 --background / --accent / --border 全为 hsl(0 0% x%)
密度优先 字号比 Web 常规小一档（正文 0.92rem），控件高 28–40px，标签栏 32×32。为的是在一屏内同时容纳四条信息流。 --text-base: 0.92rem、按钮 size-icon: size-7
状态用线，不用块 选中 / 激活态优先用 1–1.5px 描边与强调色文字表达，避免大面积填充改变布局观感。 时间轴片段选中环 box-shadow 0 0 0 1.5px var(--primary)
产物即主体 画布周围除必要控件外不放置任何装饰；预览区背景与面板背景同色，画布用一层极淡渐变托出。 PreviewPanel 与 AssetsPanel 共用 panel bg-background
读面升级 管理后台是「阅读面」而非操作面，整体字号上浮一档（13.5 / 15 / 16px），且经 body.admin-surface 作用到 Portal 层。 globals.css 中 body.admin-surface .text-sm 等三条规则

动效的红线 画布、时间轴拖动、播放头跟随不使用 CSS 过渡——它们由 requestAnimationFrame 逐帧驱动，任何过渡都会引入可感知的滞后。动画只用于「非空间性」的变化：颜色、透明度、弹出与折叠。

1.6 图标与品牌

  • 图标主体来自 Hugeicons（@hugeicons/core-free-icons + @hugeicons/react），描边风格、单一笔宽；少量使用 Lucide（Languages、Download、Eye 等）与项目自有图标（OcRippleIcon、OcVideoIcon、OcShapesIcon）。
  • 默认尺寸 size-4（16px）；工具按钮内 16px，标签栏 16px，面板内标签 16px。
  • 品牌标记为渐变方形 + 内切圆角镂空（DEFAULT_LOGO_URL = /logos/opencut/svg/logo.svg），亮色主题下用 invert 反相。
  • 品牌名在站点信息中为 MyCut；右键 Logo 可复制 SVG、下载 SVG、进入 /brand 品牌资源页。

  • 滚动区隐藏滚动条但保留滚动能力（编辑器）或使用细滚动条（内容页）

交互

  • 所有图标按钮有 aria-label
  • 破坏性操作有二次确认，且确认文案列出受影响对象
  • 键盘可完成主路径（打开项目 → 编辑 → 导出）
  • 异步操作有加载态、成功态、失败态
  • 失败提示含可复制的原始信息（长任务）
  • 快捷键提示从键位存储读取，未硬编码

一致性

  • 同一动作在不同入口的命名一致（重命名 / 复制 / 删除）
  • 项目 / 元素 / 模型的「删除」入口样式一致（弱化红字，非实心红）
  • 文案全部走 i18n，无硬编码中文或英文
  • 新增后台页面沿用「即刻生效」范式，不引入保存条
