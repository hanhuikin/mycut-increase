账户系统
Accounts — UI & Interaction

为 MyCut 引入用户账户与管理员账户体系。现状是应用完全在本地运行、没有任何账户界面， 本提案从零定义登录、注册、找回、个人中心与管理后台的界面与交互， 并定义管理员侧的大模型配置、模型授权与点数计费。

01

设计原则

四条原则约束后面所有界面与文案，冲突时以序号靠前者优先。

登录是可选项，不是门槛

MyCut 本地优先，未登录也能完整剪辑。账户的价值是云同步与多设备， 因此每个登录入口都保留「先以游客身份继续」，登录后本地项目可一键迁移上云、且绝不删除本地副本。

角色即色彩

用户旅程一律靛蓝，管理员与提权一律琥珀——取自播出间里 提示「正在录制 / 有权限」的 tally 灯。用户不需要读文字就能分辨自己身处哪一侧。

错误说实话

每条错误文案说明发生了什么、下一步做什么；不道歉、不含糊、 不指责。细节见 07 节文案表。

管理权限永远多一步

管理员不是「另一个登录页」，而是同一身份上多出的一把锁： 进入管理面板必须再次验证密码 + 动态码，且会话限时。这一步没有跳过项。

02

账户模型

三种身份，能力递增；管理员不是独立账号类型，而是用户账号上的一个角色标记。

未登录

游客

项目仅存本机。全部剪辑功能可用，导出带水印可选（产品策略另定）。

user

用户

云同步项目、多设备续剪、可选开启两步验证、点数消费与套餐订阅。默认角色。

admin

管理员

在用户能力之上，可进入管理面板：模型配置、计费管理、用户管理、角色调整、封禁、审计。强制两步验证。

03

信息架构

账户页面挂在应用外壳之外（无编辑器侧栏），管理面板独立于 /admin 命名空间并加提权门。

/                       首页（未登录：CTA 为「开始创作」；已登录：追加「继续上次剪辑」）
├─ /login               登录        公开 · 已登录则跳转
├─ /signup              注册        公开 · 已登录则跳转
├─ /forgot              忘记密码      公开
├─ /reset?token=…       重置密码      一次性令牌
├─ /settings/account    个人中心    需登录（用户）
└─ /admin               管理命名空间 · 全部需要「提权后的会话」
   ├─ /admin/enter      提权验证（密码 + 动态码）
   ├─ /admin/users      用户列表 / 搜索 / 筛选
   ├─ /admin/users/:id  用户详情 / 封禁 / 角色调整
   └─ /admin/audit      审计日志

游客与登录态共用编辑器；差异只在「素材库顶部是否出现云同步状态」与首页入口文案，编辑器内部不因登录弹任何窗。

05

模型配置与计费

管理员决定三件事——有哪些模型、谁能用、怎么扣费；用户侧只感知三件事——能用什么、这一步花多少、还剩多少。 计费采用预付费点数：先冻结、后结算、失败退回。

5.1 模型配置/ADMIN/MODELS

模型注册表是管理员侧的单一事实来源：开关、定价、提供商路由、每日上限都在这里改，改动热生效、立即反映到用户面板。

用户不接触「计费」概念，只看到点数。三个触点：面板顶部的余额、模型下拉的专业标记、生成按钮下的本次预估。

错误文案表

场景文案（主 / 副）理由
密码错误「邮箱或密码不正确」不透露哪一半错了，防枚举；表单内联展示，邮箱框不清空

动态码错误「验证码不正确」/「还剩 2 次尝试」告知剩余机会，清空已输的 6 格
动态码锁定「尝试次数过多」/「请等待 4:59 后再试」与限流同一句式，学习成本为零
账户被停用「该账户已被停用」/「如有疑问，联系支持」陈述事实与出路，不解释处罚细节
网络失败「网络连接失败」/「请检查网络后重试」可重试，按钮恢复可用
泄露密码命中「该密码出现在公开泄露记录中」/「请换一个新密码」只出现在注册 / 改密，不出现在登录
